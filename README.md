# Thomas – Site vitrine

Site vitrine responsive de Thomas, graphiste freelance (identité visuelle, UI et illustration).
Il présente son profil, ses projets et permet de le contacter.

Le site a été intégré à partir d'une maquette Figma, en HTML5 et CSS3, avec une version desktop et une version mobile.

## Installation

1. Télécharger ou cloner le dépôt GitHub.
2. Ouvrir le dossier `thomas-portfolio` dans VS Code (Fichier, Ouvrir le dossier).
3. Installer l'extension **Live Server** (dans le menu des extensions, à gauche).
4. Faire un clic droit sur `index.html`, puis choisir **Open with Live Server**.

## Police utilisée

La police est **Heebo**, chargée depuis Google Fonts. Si elle n’est pas disponible, le navigateur utilise la police sans-serif par défaut.
